<h2>Approach</h2>
<p>Trading is framed as a sequential decision problem. At each step the agent observes features of recent prices and chooses to buy, sell or hold. Because the state space is continuous, a tabular Q-table is replaced by <strong>approximate Q-learning</strong>, where Q-values are a linear function of the state features and the weights are updated from the temporal-difference error.</p>
<div class="eq">\[ Q(s,a) = \mathbf{w}^\top \mathbf{f}(s,a), \qquad \mathbf{w} \leftarrow \mathbf{w} + \alpha \big[ r + \gamma \max_{a'} Q(s',a') - Q(s,a) \big]\, \mathbf{f}(s,a) \]</div>
