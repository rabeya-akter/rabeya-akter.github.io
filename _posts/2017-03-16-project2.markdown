<h2>Motivation</h2>
<p>Social robots are increasingly proposed as companions in care settings, but it is unclear how their emotional support compares with a human's. This project measures that gap directly, using the same emotional situations and the same questionnaire for both sources of support.</p>

<h2>What we built</h2>
<ol class="steps">
  <li><strong>Emotion-specific behaviours</strong>We programmed NAO with response behaviours for happiness, sadness and fear, so the robot reacts appropriately to each emotional state.</li>
  <li><strong>Study protocol</strong>Participants experience support from both NAO and a human. Informed consent, an observer present at all times and a controlled, distraction-free room keep the sessions safe and comparable.</li>
  <li><strong>Questionnaire</strong>A structured questionnaire scores each session on emotional impact, comfort, communication clarity, overall satisfaction and personal preference.</li>
</ol>

<h2>Analysis</h2>
<p>Scores for NAO and human support are compared per emotion to find where the robot is competitive, where it falls short, and what would make robotic emotional support more effective.</p>
